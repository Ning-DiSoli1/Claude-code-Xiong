一、主站 www.qzhiyuan.com（高考志愿填报系统）

严重 1. CORS 跨域配置不当

API 接口存在严重的 CORS 配置缺陷：当请求携带 Origin 头时，Access-Control-Allow-Origin 会反射回请求的 Origin，同时设置了 Access-Control-Allow-Credentials: true。

攻击者可在任意恶意网站构造请求，利用已登录用户的 Cookie 凭证发起跨域请求，窃取用户敏感数据。

$ curl -H "Origin: https://evil.com" https://www.qzhiyuan.com/api/cust/regAndLogin
-> Access-Control-Allow-Origin: https://evil.com
-> Access-Control-Allow-Credentials: true

严重 2. MD5 签名盐值硬编码在前端 JS 中

在 index.87b905cf.js 中发现微信登录的 MD5 签名盐值被硬编码，攻击者可伪造 paramSign 绕过签名校验。

签名盐值: 25raHVwZ2xnemhsbW9jdHBkbGRkZ2dka2pkdG92aHB3ZGVoYHBoAAA
签名逻辑: Md5.hashStr(openid + phone + smsCode + salt)

高危 3. 缺少关键安全响应头

缺失的安全头风险
X-Frame-Options页面可被嵌入 iframe，存在点击劫持风险
X-Content-Type-Options存在 MIME 类型嗅探风险
Content-Security-Policy无 CSP 防护，可被执行 XSS 攻击
Strict-Transport-Security未强制 HSTS，存在 SSL 降级风险
Referrer-Policy请求可泄露 Referer 信息
Permissions-Policy未限制浏览器特性权限

高危 4. nginx 版本信息泄露

错误页面暴露 nginx/1.24.0 版本号：

Server: nginx
<hr><center>nginx/1.24.0</center>

中危 5. 前端 SPA 路由导致敏感路径探测

所有未匹配路由均返回 SPA 主页面（2283 字节），包括 /actuator/* 等路径，可能暴露内部架构信息。

中危 6. 敏感 API 端点在 JS 中明文暴露

前端 JS 包含 30+ 个 API 端点：

  • /cust/regAndLogin — 注册/登录
  • /cust/autoLogin — 自动登录
  • /cust/customer/updatePwd — 修改密码
  • /cust/customer/queryAccountByPhone — 账号查询（可枚举）
  • /cust/customer/getCustomerInfo — 用户详情

二、后台 erp.gaokaoquan.cn + saas_api.gaokaoq.com

严重 1. CORS 配置致命缺陷

saas_api.gaokaoq.com 的 CORS 配置违反 W3C 规范：

Access-Control-Allow-Origin: *
Access-Control-Allow-Credentials: true   ← 规范禁止此组合!
Access-Control-Allow-Methods: *
Access-Control-Allow-Headers: (几乎所有请求头)

严重 2. 登录接口无速率限制

POST /admin/login 无任何登录频率限制。验证码尺寸仅 120×36 像素，纯数字，可结合 OCR 进行暴力破解。

登录参数: admin_name + password + captcha + captcha_key
连续5次请求均正常响应，无锁定/延迟机制

高危 3. 缺少所有安全响应头

ERP 系统完全没有任何安全 HTTP 响应头。

高危 4. HTTP 明文传输，未强制 HTTPS

erp.gaokaoquan.cn 在 HTTP(80) 和 HTTPS(443) 均可访问，登录凭据可能在 HTTP 连接上被中间人窃取。

高危 5. 框架信息泄露

  • Laravel 框架可通过 Cookie 格式 (XSRF-TOKEN) 识别
  • 响应头 Set-Cookie: wxgk_session 暴露 Session 机制
  • 默认 Laravel 欢迎页面仍可访问

中危 6. 100+ API 路由在前端 JS 完全暴露

模块暴露的端点
财务管理/admin/finance/recharge, /withdraw, /withdrawCancel, /getSMSCode, /checkSMSCode
支付接口/admin/pay/alipay, /weixin, /aliOrderQuery, /wxOrderQuery
用户管理/admin/user/index, /edit, /export, /admin/admin/delete
站点配置/admin/site/config, /configEdit, /domainIndex, /domainEdit, /payIndex
文件上传/admin/upload
微信管理/admin/wechatManager/auth, /sendcode, /unbound
其他/admin/sms/*, /admin/refresh, /admin/me, /admin/enums 等

中危 7. 验证码接口设计缺陷

GET /captcha/api 返回 JSON 格式，含 base64 图片和 key，便于程序化提取：

{"sensitive":false, "key":"...", "img":"data:image/png;base64,..."}

验证码为纯数字、120x36像素，无扭曲干扰，可被 OCR 识别。

低危 8. CNZZ 统计代码泄露

页面嵌入 CNZZ 统计代码 (站点ID: 1280095131)，可查询该站点访问统计数据。

低危 9. HTTP 方法泄露

OPTIONS /admin/login -> Allow: GET, HEAD, POST, PUT, DELETE, OPTIONS, PATCH

三、修复建议

优先级修复项说明
P0 修复 CORS 配置 设置可信 Origin 白名单，不要反射 Origin
P0 移除前端 JS 中的签名盐值 签名逻辑迁移到服务端执行
P1 添加安全响应头 CSP, X-Frame-Options, HSTS, X-Content-Type-Options
P1 登录接口添加速率限制 IP + 账号维度限流，连续失败锁定
P1 强制 HTTPS 跳转 所有 HTTP 请求 301 重定向到 HTTPS
P1 隐藏服务器信息 nginx: server_tokens off; 移除默认页面
P2 Cookie 安全加固 设置 Secure, HttpOnly, SameSite=Lax
P2 加强验证码安全性 增加干扰元素、扭曲、字符混合
P3 部署 WAF + 定期安全测试 阿里云 WAF、年度渗透测试
